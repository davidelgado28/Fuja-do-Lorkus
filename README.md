# Fuja-do-Lorkus

No Jogo 2D - Fuja do Lorkus, o seu objetivo é bem simples, você pode escolher ser um garoto ou uma menina, e tentar escapar da aula do professor Lorkus. 

Só que tudo é dificultado, pois há livros que serão arremessados pelo Lorkus, e se você ser atingido, você será pego, e terá que reiniciar todo o seu progresso! Se você aguentar por 30 segundos e não for atingido por nenhum livro, você consegue escapar da aula.

O jogo foi desenvolvido por David Carlos Miranda Delgado, através de Orientação a Objetos em Python no arquivo main.py; O arquivo setup.py é só para executar o main.py e gerar o arquivo executável(.exe).
